# MVP 设计说明（DeepSeek + 爬取数据 + 策略决策）

核心原则：环境 > 情绪 > 个股 > 技术。

## 第一版范围

1. 大盘环境：上涨/下跌/平盘/涨停/跌停/炸板率估算。
2. 爬取数据：支持普通 HTML 和 RSS，把外部新闻/公告/情绪源作为 AI 上下文。
3. DeepSeek 分析：结合爬取数据、市场环境、候选股，输出情绪、风险分、建议动作、关键依据。
4. 策略决策：AI 分析之后再由硬风控和策略规则决定是否允许开仓、动作和仓位。
5. 实时通知：每轮扫描完成立刻终端输出；可选 Webhook 推送。
6. SQLite 留痕：每小时扫描结果可复盘。

## 当前边界

- 炸板率仍是基于快照字段的 MVP 估算，不是 Level2 真实炸板统计。
- DeepSeek API 不可用或未配置 Key 时，会自动使用本地规则 AI 兜底。
- Webhook 是通用 JSON POST，具体推送到微信/飞书/企业微信需要用户提供对应机器人地址或中转服务。

## 后续阶段

- 使用真实历史 K 线完善横盘突破、缩量、近期涨停、一进二。
- 增加多源爬虫、公告解析和新闻去重。
- 增加回测与真实交易执行前的风控校验。
