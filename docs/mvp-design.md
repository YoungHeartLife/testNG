# MVP 设计说明

## 核心原则

系统所有判断遵循：环境 > 情绪 > 个股 > 技术。

## 第一版服务边界

1. 市场环境 Agent：统计上涨/下跌/涨跌停/炸板率，输出风险等级与是否允许开仓。
2. 选股 Agent：通过手写因子解释候选股票，包括近期涨停、放量长上影、缩量抗跌、横盘突破、一进二。
3. 风控 Agent：执行 4000 家下跌禁止开仓、高风险禁止追高、中风险轻仓试错等 MVP 规则。
4. Web 实时页：通过 HTTP 首屏快照 + WebSocket 增量刷新展示仪表盘。

## 后续扩展

- 接入 Celery 周期任务，将每分钟扫描结果写入 PostgreSQL 与 Redis。
- 替换演示股票池为 AkShare/Tushare/Level2 的真实行情与历史 K 线。
- 引入 OpenAI API/LangChain 对因子组合、复盘文本和交易解释进行增强。
- 增加回测系统、交易日志、账户风控和 AI 复盘。
